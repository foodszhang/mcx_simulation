# 项目说明文档 / README

---

## 1. 项目简介
本项目是针对医学/生物成像（如荧光/红外光学模拟）的大型仿真与数据处理工具库，主攻体积仿真批量自动生成、投影与多场景高性能批处理。聚焦深度学习科研与生信工程，所有代码和说明均为中文。

## 2. 主要特性
- 支持批量自动生成符合医学/生物多介质条件下的仿真配置。
- 支持高性能体积光学仿真（MCX），流程批量化、可复现、结果可靠。
- 多角度、多模态投影与可视化后处理，适配下游深度模型。
- 所有脚本及工具划分明晰，模块化易维护。

## 3. 目录结构概览
```
项目根目录/
├── src/        # 主流程与仿真/数据生成相关代码
│   ├── batch_config_generator.py
│   ├── batch_simulation_runner.py
│   ├── batch_postprocessor.py
│   ├── ...
├── tools/      # 数据、投影、格式、材料相关工具与可视化
│   ├── vis_3d.py
│   ├── show_proj.py
│   ├── ...

├── AGENTS.md   # 项目详细交接和开发说明文档（中文）
├── pyproject.toml  # Python依赖规范

```

## 4. 安装与依赖管理规范
- 必须用 [uv](https://github.com/astral-sh/uv) 工具，**禁止直接用pip**。
- 依赖添加示例：
  ```bash
  uv add numpy torch matplotlib
  ```
- 所有脚本运行请用 uv：
  ```bash
  uv run python main.py
  ```

## 5. 主要流程快速上手
1. 批量体积仿真配置生成、自动体积仿真、批量投影全流程一键执行：
   ```bash
   uv run python main.py
   ```
   输出目录会自动生成所有配置、仿真结果与多视角投影。

2. 其他常用组件/可视化
   - 三维体积预览：
     ```bash
     uv run python tools/vis_3d.py
     ```
   - 数据预处理等详见 src/ 与 tools/ 目录下脚本注释。

## 6. 最佳实践与开发建议
- 代码风格、文档与输入输出均为中文
- 强烈推荐每次主流程功能或重要算法新增后补交AGENTS.md文档与典型用例
- 核心仿真过程及数据必须严格复现、零手改配置
- 深度学习、医学与生物科学流程必须使用隐私与合规最佳实践
- 性能与可维护优先，推荐多进程/批处理避免内存瓶颈
- 每次环境部署、依赖变更都必须用uv和pyproject.toml管控
